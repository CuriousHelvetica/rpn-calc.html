# Project ideas

Ideas for future projects, kept here so they aren't lost between sessions.

## Built

- **RPN trainer** — a game inside the calculator (TRAIN button). Key in a
  formula the RPN way. Two modes: *Countdown* (solve as many as you can in
  60 s) and *Keystroke par* (10 formulas, no clock, fewest keystrokes).
  Five levels of difficulty.

## Building on the calculator

- **HP-15C programming mode** — record and run keystroke programs, with
  labels, `GSB`/`RTN` and conditional tests, like the real 15C.
- **"Paper tape" history** — a printer-style strip beside the display that
  scrolls out each operation and stack result, and can be exported.

## Something new, in the same retro, tactile style

- **Pocket synth or drum machine** — a 16-step sequencer styled like vintage
  hardware, reusing the Web Audio approach from the key clicks.
- **Nixie-tube or flip-clock desk clock** — a PWA with timers and alarms,
  with a mechanical feel.
- **Unit and base converter** — styled like an old slide rule, with a sliding
  scale you can drag.
